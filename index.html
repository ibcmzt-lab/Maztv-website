How to Install MazTV

Already have your MazTV username and password? Follow the steps below to install the app and start watching.

Most common

Amazon Firestick / Fire TV

⌄
  1. 1. Install Downloader

    From your Fire TV home screen, search for Downloader and install the Downloader app.

  2. 2. Allow Downloader

    If your Fire TV asks for permission to install apps from Downloader, allow it. If needed, go to Settings → My Fire TV → Developer Options → Install Unknown Apps → Downloader and turn it on.

  3. 3. Enter the MazTV code

    Open Downloader, select its address/search field, and enter the MazTV Downloader Code:

    5130929
  4. 4. Download and install

    Let the MazTV app download. Select Install when prompted. When installation is finished, select Open.

  5. 5. Sign in

    Enter the username and password that MazTV provided to you. Enter them exactly as provided.

  6. 6. Start watching

    Once your login is accepted, your MazTV service will load. You can then start watching the channels and content included with your plan.

Tip: After installation, you can delete the downloaded installer file from Downloader if prompted. This does not uninstall MazTV.
Android TV

Android TV / Google TV

⌄
  1. 1.

    Install Downloader from Google Play on your Android TV or Google TV device.

  2. 2.

    Open Downloader and follow any permission prompts needed to allow it to install an app.

  3. 3.

    Enter the MazTV Downloader Code 5130929 in Downloader and select Go.

  4. 4.

    Download and install the MazTV app, then open it.

  5. 5.

    Enter the MazTV username and password provided to you.
